# DietHelper-Monorepo

Клиент-серверное приложение для подсчета калорий и отображения статистики потребления макронутриентов. Проект выполнен в рамках выпускной квалификационной работы бакалавра (2026 г.).

## Основные возможности
- Регистрация и вход в систему с безопасной JWT-аутентификацией (access- и refresh-токены).
- Ведение личного справочника продуктов: добавление из общей базы, ручное создание, поиск по штрихкоду через OpenFoodFacts.
- Создание блюд двух типов: составных (с автоматическим пересчетом КБЖУ) и готовых.
- Дневник питания с группировкой по приемам пищи (завтрак, обед, ужин, перекус).
- Навигация по дням в виде карусели недели; редактирование порций и состава блюд.
- Автоматический расчет суммарной калорийности и макронутриентов за день.
- История записей на основе снэпшотов: данные фиксируются на момент добавления и не меняются при изменении справочников.
- Модуль статистики с гибким выбором периода (3 дня, неделя, месяц, произвольный диапазон) и экспортом отчета в текстовый файл.
- Клиентская сессия шифруется средствами Windows DPAPI.

*Полное описание архитектуры, моделей данных и руководство пользователя содержатся в пояснительной записке (доступна по запросу).*
